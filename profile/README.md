<p>纯净度不是官方指标，但能通过几个侧面推断出来。这篇先解释这个概念到底指什么，再给四个可以自己查的维度，然后讲黑名单和验证码的区别，最后列验收要做哪几件事和采购时容易踩的四个坑。</p>
<h2>一、纯净度指的是什么</h2>
<p>纯净度不是一个官方指标，是行业里的说法。大意是这个地址过去没被大量用于自动化行为，没有被目标站点标记过。</p>
<p>它没有统一的分值，只能通过几个侧面推断：归属是否真实、是否在公开黑名单、历史行为是否混杂、当前是否被频繁验证。</p>
<p>所以别信纯净度百分之多少这类说法。没有公认的评测口径，数字多半是营销话术，不如自己查。</p>

<p>归属和类型是最基础的两项，用公开查询工具就能看。黑名单需要多查几个库，单一库覆盖不全。</p>
<p>历史比较难查。能看的是公开举报记录和地址段的使用密度，间接判断这个段是不是被大量用于同类业务。</p>
<p>四个维度都正常，也不能保证一定好用。平台的风控是动态的，地址只是其中一项输入。</p>
<h3>为什么同一段地址表现差别大</h3>
<p>同一段里不同地址的使用历史不同。有人用得干净，有人跑过大量任务，表现自然不一样，所以要逐个验。</p>
<h2>三、ASN 和归属怎么核</h2>
<p>先查 ASN 编号和名称，对照目标国家的运营商名单。编号对不上，说明地址不在那个运营商的网里。</p>
<p>再查组织名。组织名写的是云服务商、主机商、CDN，基本可以判定不是住宅资源，无论卖家怎么解释。</p>
<p>最后查地址类型标记。标记为商业或托管，和标记为住宅，在外部看来是不同的身份，用途上要区别对待。</p>
<h2>四、黑名单和验证码是两回事</h2>
<p>进黑名单是地址被明确标记，表现为邮件被拒、访问被拦。频繁弹验证码是风控评分偏低，程度轻一些但同样影响使用。</p>
<p>两者要分开判断。黑名单能查到记录，验证码只能靠实测。买之前最好两样都测，只看一项会误判。</p>
<p>还有一种是被目标站点静默限制，不报错但功能受限。这种最难发现，通常要在真实业务操作中才能暴露。</p>
<h2>五、验收时做哪几件事</h2>
<p>第一，用两三个工具交叉查归属，看结果是否一致。第二，查主要黑名单库，看是否有近期记录。</p>
<p>第三，在真实环境跑一遍业务操作，观察是否触发验证、是否被限速。第四，连续观察三到五天，看地址是否稳定。</p>
<p>第五，做一次重连测试。地址变化说明是动态池，和静态的描述不符，这属于交付不达标。</p>

<h2>六、购买时容易踩的坑</h2>
<p>第一个坑是把机房段当住宅卖。看 ASN 就能识破，但很多人只看卖家给的截图，截图可以挑好看的。</p>
<p>第二个坑是共享池当独享卖。一个地址多人轮换，用几天就开始频繁验证，追溯时才发现不是独享。</p>
<p>第三个坑是低价长约。一次性付一年，用两个月发现不能用，退款条款又没写清楚，钱就压在里面了。</p>
<p>第四个坑是不留记录。口头承诺的更换、带宽、独享，出问题时全都不认，只能自己承担。</p>
<h3>怎么降低踩坑概率</h3>
<p>小额试、逐项验、写进合同、留好记录。四件事做到，大部分坑能避开，剩下的属于不可控风险。</p>
<h2>常见问答</h2>
<h3>原生 IP 纯净度有官方标准吗？</h3>
<p>答：没有。这是行业内的经验说法，没有统一的评测机构或分值。只能通过归属、类型、黑名单、历史记录几项自行判断。</p>
<h3>为什么查出来是住宅，用起来还是被验证？</h3>
<p>答：地址归属只是风控的一个输入。登录行为、设备指纹、操作频率都会影响判定，单靠地址无法决定结果。</p>
<h3>共享住宅 IP 一定不能用吗？</h3>
<p>答：不是一定，但风险更高。共享意味着地址历史混杂，长期固定账号用途建议选独享，短期采集可以接受共享。</p>
<h3>买之前能要求提供检测报告吗？</h3>
<p>答：可以要求，但报告只能作参考，最好自己复测。用不同工具交叉验证，比看供应商提供的截图可靠。</p>
